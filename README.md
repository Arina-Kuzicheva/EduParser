# ProfOrientation Parser — модуль сбора и агрегации данных

Модуль автоматизированного сбора, очистки и агрегации данных для
информационно-аналитической системы профориентации школьников и
формирования индивидуальных образовательных траекторий.

Реализует **Data Node** из архитектуры ИАС: собирает сведения о вузах,
колледжах, образовательных программах, вакансиях, профессиональных
стандартах и рейтингах из открытых российских источников, приводит их
к единой схеме и загружает в гибридное хранилище (PostgreSQL + MongoDB).

> Часть дипломного проекта «Разработка информационно-аналитической
> системы профориентации и формирования индивидуальных образовательных
> траекторий для школьников» (БГТУ, каф. «Компьютерные системы и технологии»).

## Возможности

- **Мультиисточниковый сбор** — плагинная архитектура адаптеров:
  добавление нового источника без изменения ядра (`sources/` + реестр).
- **Инкрементальное обновление** — дедупликация и upsert по стабильным
  ключам (`source_id + external_id`), обновление только изменившихся записей.
- **Очистка и валидация** — отсев выбросов, устранение пропусков
  (медианная импутация / модельная), нормализация числовых показателей,
  кросс-валидация между источниками.
- **Текстовая предобработка для NLP-модуля** — токенизация, лемматизация
  (pymorphy3), удаление стоп-слов, нормализация; извлечение сущностей (NER):
  профессии, навыки, предметы ЕГЭ, названия вузов.
- **Фильтрация шумов и накруток** — эвристики против фейковых/ангажированных
  отзывов, детект ботов по поведенческим признакам.
- **Гибридная загрузка** — структурированные данные в PostgreSQL,
  тексты/отзывы/JSON-выгрузки — в MongoDB.
- **Наблюдаемость** — структурные логи, метрики Prometheus, отчёты о качестве
  данных (полнота, дубли, доля пропусков по полям).
