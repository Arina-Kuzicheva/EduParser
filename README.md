# ProfOrientation Parser — сбор данных для системы профориентации

Модуль автоматизированного сбора, очистки и сохранения данных для
информационно-аналитической системы профориентации школьников.

Программа собирает сведения о вузах, колледжах, программах обучения и 
вакансиях из открытых источников, приводит их в порядок и сохраняет в базы данных. 
Этот модуль является «поставщиком данных» (Data Node) для остальных частей 
системы — алгоритмов подбора профессий и аналитики.

> Часть дипломного проекта «Разработка информационно-аналитической
> системы профориентации и формирования индивидуальных образовательных
> траекторий для школьников» (БГТУ, каф. «Компьютерные системы и технологии»).

## Что умеет программа

- **Собирать данные с разных сайтов** — легко добавлять новые сайты-источники, не переписывая всю программу.
- **Обновлять только новое** — программа не создает дубли, если данные уже есть, а обновляет только изменившиеся записи.
- **Чистить и проверять** — отсеивает битые данные, заполняет пропуски, приводит цены и баллы к единому виду.
- **Разбирать тексты** — ищет в отзывах и описаниях названия профессий, навыков и предметов ЕГЭ.
- **Раскладывать по базам** — цифры и строгие данные (баллы, цены) идут в одну базу, а тексты (отзывы, сочинения) — в другую.
